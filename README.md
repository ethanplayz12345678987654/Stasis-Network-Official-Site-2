# Stasis Network — Neon Gold Theme

This adds a small static website to your repository with a neon-gold Minecraft-inspired look and scroll-triggered graphics.

Files added:
- index.html — main site
- styles.css — styles and neon/gold theme
- script.js — scroll reveal, parallax, and floating block particles

How to preview:
1. Clone the repo and open index.html in a browser.
2. Or use GitHub Pages: enable Pages for the repository (Settings → Pages) and point to the `main` branch root.

Notes:
- Graphics are CSS/SVG-based so there are no external assets to commit.
- Tell me if you want a different branch, real server IP, custom logo, or additional pages (store, forums, whitelist, etc.).
